Invalid JSON/values fail rather than reset defaults.

## Retirement, rollback, Stop and Unknown

Only after verified target readiness/Commit may the owning manager retire the reviewed legacy installation:

- **Brew:** actual `brew uninstall hanbong5938/tap/herdr-desktop-pet`; never another formula, beta or a broad cleanup.
- **Herdr managed:** refresh the same registry to immutable integration-only v0.4.1 / `6d2ac0446f6ecb84f179e21fac3c5b02e07dc8e8`, then remove its generated plugin-local app. Faulty v0.4.0 is ineligible. This is a one-time migration action, not ordinary native updating.
- **Linked/local source:** preserve checkout, Git origin and user changes; remove only the approved generated legacy bundle, never clean/reset source.
- **Manual archive:** retire only the reviewed exact bundle.

On pre-Commit readiness failure restore the exact original bridge image and prior locator/default-profile records. Restart it only while the original authorization is valid and **no user Stop** occurred. User Stop forbids automatic target restart and rollback start, including while a genuine manager is completing.

A definite nonzero **quiescent** retirement is a distinct incomplete committed state. Keep the ready target and all first-attempt evidence/logs. Remove only an independently evidenced owned fault resource, if one was introduced; then use the **current committed target's real native same-plan Resume review and independent final consent**. Resume Cancel must retain the failed record/attempt without a new manager intent. Never restart an old source or manufacture another plan to obtain Resume.

**Unknown manager execution is not retryable.** Preserve its signed matching helper, immutable plan, journals, reservation, actual manager intent and both installation histories. An absent old root or exited process does not retrospectively supply a missing exit acknowledgement. Actual public-source fault operation **`173717884a6dfc4b1015b4560b0d35b8`** killed only the attested helper after real Brew PID=PGID1576 launched; the committed public target remained ready, the manager removed the source, but the record stayed `manager_unknown` and reserved with no new intent over 60 sampled seconds. Normal discovery must not expose a retired legacy app or permanent old-name alias as the shared app. Retain historical evidence without promoting its old protocol to fresh write/execute/startup/resume authority.
