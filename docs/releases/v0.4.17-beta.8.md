# Desktop Pet v0.4.17-beta.8 release notes

## Session connection recovery and truthful empty states

This testing-only prerelease follows the public [beta.6](v0.4.17-beta.6.md). Stable v0.4.16 remains latest; existing releases, stable formulas and default plugin channels are unchanged. Installing this beta does not opt a profile into automatic beta updates.

The immutable beta.7 source passed its CI test/build gate but packaging rejected a stale beta.6 approval constant, so no beta.7 app was published. Beta.8 synchronizes the packager's approved version and the compiled neutral app/helper identity with product metadata. The failed tag is preserved, not overwritten. The paired plugin's beta.2 changes manifest/release metadata only; its tested window implementation is unchanged.

- Distinguish **No connection**, **Disconnected**, a healthy empty session inventory and a filter with no matches. The native session list uses the existing connection summary instead of reporting every empty list as “No sessions.” English, Korean, Japanese and Simplified Chinese labels and usage guidance are included.
- Bundle Tern plugin **0.2.2-beta.2**. Collect tabs, sessions, agents, hosts and panes in separate continuations; separate KV validation, inventory construction, JSON encoding and native process work. Chunk inventory construction at bounded checkpoints instead of stacking avoidable work in one callback.
- Retire a stalled exchange at its ten-second deadline on the next viable trigger. Fence dropped, duplicate and late continuations with one-use tickets and source incarnation checks. Never replay an uncertain semantic ask or reuse retired receipts.
- Immediately before delivery, synchronously revalidate the live pane and its unique session/tab membership, then recheck the deadline in the same callback as the semantic ask. Moved, renamed, closed, newly parked or ambiguous targets fail closed; an unchanged already-parked target remains eligible. Unrelated malformed remote membership does not block a valid local target.
- Preserve beta.6's authenticated migration authority, exact-owner recovery, preference ownership and protected restart behavior. The compiled Tern adapter and bundled consumer share immutable revision `bd0916b62117569a846aacf9c641d74d23799eb7`; package digests and exact plugin-version admission advance together. No local path dependency is shipped.

## Verification and limits

The unchanged integrated production plugin passed **209/209**, `done=true`, no fatal error, in an isolated actual **Tern 0.9.5** window. The harness controls inventory, KV, prompts, subprocesses and asks; no real agent ask escapes it. Retained installation/handover cases and the new recovery/final-target cases run together. This is not a real model-delivery or migration crash-recovery claim.

Before the release-metadata correction, the recovery candidate passed the locked native workspace, including the empty-list transition regression, **8** Core/Herdr composition tests and **44** Tern adapter tests. Production composer and recovery/reset/restart/detail-only AppKit executables passed on the main thread. TypeScript checking, **68** script/rig tests, deformation and Rust formatting passed. Beta.7's CI independently passed its full test/build gate; that did not qualify its failed package. These observations use immutable published adapter revisions without local dependency overrides.

The exact beta.8 tag separately gates TypeScript, release/rig tests, deformation, Rust formatting, the locked native workspace and Core/Herdr composition. Its workflow builds and verifies the arm64 app, paired helper, signatures, capabilities, default character and signed-resource digest closure, then creates six immutable assets as a non-latest prerelease draft. Downloaded artifact qualification is required before public release; a source commit or draft alone is not an installed-runtime result.

A callback already disabled by Tern's watchdog requires plugin reload or a fresh window VM. Connect alone cannot revive disabled hooks. The final synchronous safety check deliberately does not promise every callback stays below 50 ms under arbitrary host delay. OS scheduling, machine sleep/lock and unavailable host callbacks cannot be repaired by a timer that no longer runs. Genuine signed coordinator crash-boundary and physical keyboard/IME/VoiceOver acceptance retain the limitations documented in beta.6.

Contracts 0.1.0, legacy 0.3.16, updater protocol 4, observation 2, integration API 1, migration handover 1 and `MIGRATION_TARGET_VERSION=0.4.12` remain unchanged. Herdr remains pinned to `0b9e24b2f6498311229a328ad144a4ab41b7505b`.

## Local beta application

Use the versioned installer asset and its checksum for this release. Preserve the native executable/config/state connection triple and existing profile. After the beta app is installed, install its exact signed consumer package:

```sh
tern plugin install "$HOME/Applications/DesktopPet.app/Contents/Resources/integrations/tern-desktop-pet" --force
```

This reloads plugins without restarting Tern or sending a model prompt. Verify both the running app version and a fresh Tern connection afterward; a plugin's `ready` status alone does not prove native data is connected.
