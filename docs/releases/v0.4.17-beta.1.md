# Desktop Pet v0.4.17-beta.1 release notes

## The v0.4.16 fixes on the beta channel

This prerelease carries the same runtime fixes as stable v0.4.16. It is a version/channel cutover, not a new runtime feature or an additional recovery fix. Stable v0.4.16 remains latest; this beta must not replace it as the latest stable release.

The detached installer helper continues to clear its inherited environment with `env_clear` while reconstructing trusted `HOME` from the operating system account lookup. This preserves v0.4.16's correction for the metadata query failure `HOME must be an absolute path`, without inheriting caller-controlled HOME, startup/updater tokens or unrelated environment variables. The existing ownership ACK, lease, immutable plan/request, Stop-generation and installation guards are unchanged.

The authenticated SDK validation-child and post-exchange namespace corrections inherited by v0.4.16 are also retained. An unowned preparation still requires its matching helper's same-ID recovery cleanup; it is not replayed as a new installation or manually rewritten. A new installation requires its own approved operation.

Relocation regression fixtures now model an explicitly Stable installed parent independently of the compiled beta version. The production rule still requires the exact compiled Stable target; a beta does not gain relocation or legacy migration authority.

## Preservation and compatibility boundaries

Original config/state, characters, settings, retained originals and Tern/window work remain authoritative. No Tern restart, plugin reload, consumer reinstall, native KV rewrite or profile adoption is introduced. Helper settlement, a separately approved ordinary Pet start and actual fresh Tern bindings remain distinct evidence.

Legacy migration authority remains `MIGRATION_TARGET_VERSION=0.4.12`. Legacy `0.3.16`, contracts `0.1.0`, protocol 4, observation 2, integration API 1, migration handover protocol 1 and all qualified adapter/consumer pins remain unchanged. Existing legacy warnings remain; this release is not claimed to be diagnostic-free. Homebrew formulae are unchanged.

## Publication and verification boundaries

The workflow prepares a draft prerelease for the exact tag `v0.4.17-beta.1`, with `draft=true`, `prerelease=true`, `make_latest=false` and asset overwriting disabled. Existing tags, assets, releases and frozen release notes remain immutable.

Stable v0.4.16's existing build, test and publication evidence does not establish qualification of the new beta bytes. Final local gates, exact tagged CI and independent asset verification must be reported separately. No beta live installation on mini was performed or is claimed. Applying a future-version update from this beta remains untested. Source or release verification alone is not evidence of affected-machine recovery, live Stop/restart or Tern continuity.

The package remains ad-hoc signed, not Developer ID signed or notarized.
