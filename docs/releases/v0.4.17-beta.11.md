# Desktop Pet v0.4.17-beta.11 release notes

Testing-only prerelease. Stable/default channels and automatic beta preferences are unchanged.

## Tern sessions: remove the hot subprocess boundary

Actual Tern 0.9.5 attribution identified the regular `tern.process.run` launch for `tern-exchange` still pending when the callback watchdog fired. This release carries the authenticated loopback HTTP transport from the frozen beta.10 source tag and pairs it with Tern consumer **v0.2.2-beta.3**, pinned at `77c635a5a9f0b4c55a2fc538f40c48f5ec9c145d`.

Regular exchanges use `tern.fetch`, not a subprocess. The private, bounded endpoint descriptor binds the exact profile and live instance; authenticated POSTs retain existing source identities, snapshots, command validation, receipts and deadlines. HTTP admission is bounded independently of Unix control connections. Proxy ambiguity, malformed descriptors, origins, hosts, framing and duplicate JSON keys fail closed. Signed setup and approved handover subprocesses remain; exchange never falls back to the failing subprocess path. Profile/endpoint changes fence replies and final semantic actions.

The beta.10 annotated source tag remains immutable. Its artifact workflow was cancelled before release/assets were created so this successor could include the coordinated canonical replacement below; beta.10 is not a published app to install.

## Canonical stopped-source operator replacement

A raw replacement after an installed-only recovery would leave the latest operation describing the old image. Do not bypass that mismatch by copying an app or deleting history.

`install-manual-recovery --request ABS` now accepts an explicitly authorized **version-3** request with `confirmation:"replace_canonical_app_preserve_profile_allow_beta"` for an already-canonical stopped source and a strictly newer, independently signed official beta. It preserves the exact owner/profile and uses the existing retained same-root atomic exchange, with a new immutable plan, exact operator consent and truthful installation record. The original signed app and prior records remain retained. Version 1 is still stable-only H → C; version 2 is still separately opted-in beta-only H → C. Scope/token/schema substitutions are rejected.

No native confirmation panel, synthesized Stop ACK, updater parent or restart permission is introduced. The source must already be normally stopped and the Stop generation unchanged. Success remains `installed_stopped`, `applied:false`, `restart:"not_requested"`. A separately approved normal Start follows verified reservation release. C → C does not rewrite the saved Tern route or issue relocation handover authority. Preserve config/state, characters, settings and existing journals; do not stop or restart Tern. See the [CLI contract](../cli.md).
