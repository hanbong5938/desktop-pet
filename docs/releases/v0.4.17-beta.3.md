# Desktop Pet v0.4.17-beta.3 release notes

## Restart from Settings

This testing-only prerelease adds **Restart App** immediately to the left of **Quit** in the compact Settings footer. It retains the three-tab Settings and native detail windows introduced in [beta.2](v0.4.17-beta.2.md). Stable v0.4.16 remains latest; this is not a stable promotion.

- Restart uses the running executable, config/state profile, live observation mode, original asset override and integration launch options. It does not download, install, rebuild, adopt a profile or change automatic-start settings.
- Existing restart admission checks protect unsaved drafts, IME composition and pending work. A refused request or failure to spawn the restart command leaves the running app alive and reports the problem.
- The action is localized in Korean, English, Japanese and Simplified Chinese, with an accessibility label and the existing mutation-freeze behavior.

## Compatibility and publication boundary

Storage schemas, CLI wire contracts and adapter pins are unchanged. Legacy migration authority remains `MIGRATION_TARGET_VERSION=0.4.12`; legacy `0.3.16`, contracts `0.1.0`, protocol 4, observation 2, integration API 1 and migration handover protocol 1 are unchanged. Homebrew formulae, the stable latest release and existing immutable releases are not changed.

The exact-tag workflow prepares a draft `v0.4.17-beta.3` prerelease with six app/installer assets and overwriting disabled. Publication follows qualification of the tagged build and its assets and remains non-latest. The package is **ad-hoc signed, not Developer ID signed or notarized**.

The earlier restart implementation was exercised in an isolated native app: the actual button action replaced the daemon instance and preserved its executable, config/state, asset override and observation mode. The Korean button frame was strictly left of Quit without overlap. That evidence preceded this latest-beta port and does not certify the final tagged bytes. The desktop session did not provide usable screenshots or external accessibility interaction; visual, physical-input, IME and VoiceOver acceptance are not claimed. Existing user installations and the default profile were not replaced.

On the beta.3 port, TypeScript checking, 62 JavaScript release/Wiki/rig tests, the locked native workspace gate and a release build passed. A throwaway native fixture then exercised the production button and handler on the beta.3 source. It exposed a nested-callback dispatch loss; the handler now uses the existing retained deferred-action mechanism. With that correction, the same fixture restarted PID 52785 to 52890 with a new instance while retaining the explicit asset override, executable, profile and live mode. It also observed refusal while startup migration admission was pending, followed by success after admission settled. The Korean footer frames were nonoverlapping (Restart x=170, width=112; Quit x=290, width=48). Fixture hooks are not shipped. Exact-tag CI and downloaded release-byte qualification remain separate from these local source observations.

## 한국어

설정창 하단의 **종료** 바로 왼쪽에 **앱 재시작** 버튼을 추가한 테스트용 베타입니다. 현재 실행 파일·프로필·관찰 모드·에셋·연동 실행 옵션을 유지하며 업데이트나 설치는 하지 않습니다. 미저장 초안·IME 조합·진행 중인 작업 등 기존 재시작 차단 조건이 있으면 실행하지 않고 안내합니다. 한국어·영어·일본어·중국어 간체를 지원합니다.

beta.2의 간결한 설정 3탭과 상세창은 유지합니다. 안정판 latest는 v0.4.16이며, 기존 설치 앱·기본 프로필·Homebrew formula·이관 권한을 변경하지 않습니다. 패키지는 ad-hoc 서명이며 공증된 앱이 아닙니다. 이전 격리 실행 결과와 최종 태그 CI·공개 자산 검증은 구분하며 실제 사용자 업데이트 성공이나 잠금 세션의 육안 검증을 주장하지 않습니다.
