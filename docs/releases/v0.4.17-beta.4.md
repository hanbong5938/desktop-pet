# Desktop Pet v0.4.17-beta.4 release notes

## Compact updates and native update log

This testing-only prerelease builds on [beta.3](v0.4.17-beta.3.md), retaining its Settings restart action and all existing updater recovery protections. Stable v0.4.16 remains latest.

- Replace **Update Details** with **Update Log** in Korean, English, Japanese and Simplified Chinese. Source, release, check time, operation/relocation information, history and diagnostics use selectable, monospaced read-only text in the existing resizable, scrollable native window. Opening the log does not check, install, restart or mutate update history.
- Move the update status icon and heading outside the compact card. Reduce status, settings and diagnostic row spacing without hiding failures, available actions or the beta warning.
- Keep **Menu Bar Settings** outside the update group, below language and above automatic start. Put **Update Settings** and **Update Log** side by side instead of stacking separate full-width rows.
- Keep log selection, scrolling and read-only navigation available while update preparation freezes mutating controls.

## Verification and boundaries

A throwaway AppKit fixture exercised the production Settings panel and native log window in all four UI languages. It verified the external header, nonoverlapping update action row, separate menu-bar settings placement, complete native log selection, long-log scrolling, reading-position preservation across refresh and freeze/unfreeze. Screenshots of the actual AppKit views were inspected. The fixture and its public entry point are not shipped. This is controlled native-view evidence, not acceptance of an actual user update transaction, physical input, IME or VoiceOver.

The port retains beta.3's separate log window instead of reintroducing the older main branch's inline diagnostics. It does not replace newer recovery, relocation, restart or Settings behavior with the older implementation. Existing user installations, default profiles, artwork and character packs are untouched.

Storage schemas, CLI wire contracts and integration pins are unchanged. Contracts 0.1.0, legacy 0.3.16, protocol 4, observation 2, integration API 1, migration handover protocol 1 and `MIGRATION_TARGET_VERSION=0.4.12` are unchanged. Homebrew formulae, stable latest and every existing release/tag/asset remain unchanged. The exact-tag workflow creates a non-latest prerelease draft with six immutable app/installer assets; publication follows qualification of that tagged build and its downloaded assets. The package is ad-hoc signed, not Developer ID signed or notarized.

## 한국어

beta.3의 앱 재시작·최신 업데이트 복구 동작을 유지하면서 업데이트 UI를 정리한 테스트용 베타입니다.

- **업데이트 상세 → 업데이트 로그**: 고정폭·선택 가능한 읽기 전용 텍스트를 기존 크기 조절·스크롤 가능한 보조창에 표시합니다.
- 업데이트 상태 아이콘과 제목을 카드 바깥으로 옮기고 행 간격·빈 공간을 줄였습니다. 오류·사용 가능한 동작·베타 경고는 유지합니다.
- **메뉴 막대 설정**을 업데이트와 분리해 언어 아래에 배치하고, **업데이트 설정 / 업데이트 로그**를 한 행에 배치했습니다.
- 업데이트 준비 중에도 로그 선택·스크롤은 가능합니다. 로그 열기만으로 확인·설치·재시작을 실행하지 않습니다.

네 언어의 실제 AppKit 설정·로그 화면에서 배치, 선택, 스크롤, 새로고침 시 읽던 위치와 조작 동결·해제를 확인했습니다. 임시 검증 코드는 배포하지 않습니다. 안정판 latest는 v0.4.16으로 유지하며 기존 설치 앱·프로필·Homebrew formula·이관 권한은 변경하지 않습니다. 최종 태그 CI·공개 자산 검증과 실제 사용자 업데이트 성공은 별개의 근거입니다.
