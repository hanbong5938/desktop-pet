# Desktop Pet v0.4.17-beta.5 release notes

## Compact settings, usable update policies and App Recovery

This testing-only prerelease builds on [beta.4](v0.4.17-beta.4.md). Stable v0.4.16 remains latest; existing tags and assets are immutable.

- Fit each detail window to its actual topic content. Small Menu Bar and Update Settings pages no longer inherit a large shared height; intentional user sizes, scroll positions and long-log viewports remain topic-specific.
- Permit automatic-check and beta-policy changes after a completed/applied update only when the exact helper lease and installation/profile scopes are proved free. Preserve history and keep active, reserved or unknown operations blocked.
- Add **App Recovery → Reset all settings…** with cancel-first native confirmation. Back up the exact profile, restore native preference/lifecycle defaults and character selection, then restart only that Pet. Unsaved edits, IME, pending work and unsettled update ownership block reset. Installed packs, original images, explicit asset paths, integration routing/registration and updater evidence/reservations are preserved. Recovery displays the latest result and backup path.
- Keep marked text and editing history intact during freeze without allowing insertion, paste, marked-text replacement or undo mutations. Read-only logs and navigation remain available.
- Add operation-bound update recovery/progress actions and an explicitly approved quit-original recovery path for compatible retained helpers. Original-process observation no longer mistakes an inherited completed startup token for new start authority. Never replay an installer or automatically restart an uncertain operation.
- Revalidate the captured executable before executable origin probes and again before recovery/reset restart; later user Stop takes precedence.

## Verification and boundaries

Local workspace Rust checks/tests, release build, TypeScript check and 62 script/rig tests passed before release preparation. Disposable production AppKit views exercised all four UI languages, compact sizing, topic-specific manual sizes and offsets, frozen/busy controls, native marked-draft preservation, and actual Cancel responses to button clicks and modal-targeted synthetic Return. Captures were inspected; temporary fixtures are not shipped. The locked session does not certify physical keyboard, IME, focus or VoiceOver.

Real isolated Source app executions verified wrong-instance rejection before Stop; custom language/theme/dialogue settings backed up and reset; fresh same-profile UI/control readiness; and preservation of both absent and explicit asset overrides. Fixtures were stopped and removed. Partial-write, stale-state, backup-failure, later-Stop, executable-drift and reservation/lease cases have isolated behavioral regressions. This is not certification of a real user's beta.5 update or a signed Standalone/Homebrew reset transaction.

Older installed apps do not acquire these buttons retroactively. An old beta2 executable lacks the independent manual-start generation contract: retained-helper cleanup does not grant it safe in-coordinator Start or automatic restart. Unknown manager evidence remains protected; do not delete reservations or replay an old installer. Resetting preferences is not updater recovery.

Contracts 0.1.0, legacy 0.3.16, updater protocol 4, observation 2, integration API 1, migration handover 1, integration pins and `MIGRATION_TARGET_VERSION=0.4.12` remain unchanged. Additive recovery/manual-start capabilities do not widen old operation authority. The exact-tag workflow stages six immutable prerelease assets for downloaded-asset qualification before publication. Packages are ad-hoc signed, not Developer ID signed or notarized. No stable latest or Homebrew formula change is included.

## 한국어

- 작은 설정 창은 내용에 맞춰 줄이고, 화면별 직접 조절한 크기와 스크롤 위치는 보존합니다.
- 완료된 업데이트 이력 때문에 자동 확인·베타 설정이 잠기는 문제를 수정했습니다. 실제 예약·진행·불명 상태는 계속 보호합니다.
- **앱 복구 → 모든 설정 초기화…**를 추가했습니다. 확인·비공개 백업 후 현재 프로필의 설정을 기본값으로 되돌리고 Pet만 다시 시작합니다. 설치한 팩·원본·연동 앱 설정·업데이트 기록과 예약은 보존합니다.
- 조작 동결 중 IME 초안은 유지하며 변경 입력은 차단합니다. 로그 선택·스크롤과 탐색은 가능합니다.
- 업데이트 복구·진행 확인·별도 동의 후 원본 종료 복구를 구분하고 설치 재실행·불확실한 자동 재시작은 하지 않습니다.

격리된 실제 앱의 백업·초기화·재시작과 네 언어의 네이티브 화면·취소를 검증했습니다. 실제 mini 설정을 초기화하거나 Tern을 종료하지 않았습니다. 구형 앱에 새 복구 버튼이 소급 적용되는 것은 아니며, beta2의 안전한 독립 시작 계약 부재를 우회하지 않습니다. 안정판 latest는 v0.4.16을 유지합니다.
