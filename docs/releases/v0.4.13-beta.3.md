# Desktop Pet v0.4.13-beta.3 release notes

Status: **Beta prerelease — opt-in testing, not a new stable release.** This update-discovery and migration-history repair follows [v0.4.13-beta.2](https://github.com/hanbong5938/desktop-pet/releases/tag/v0.4.13-beta.2). Beta software may be unstable or contain bugs. Stable `0.4.12` remains the latest stable release and the authorized migration target; this publication does not promote beta to stable or change stable installer pointers, Homebrew, or migration pins.

## Changes

- Recognize the neutral repository's canonical `v`-prefixed beta tags, including `v0.4.13-beta.2`, during both catalog parsing and release-candidate revalidation. Download URLs and checksum validation remain bound to that exact tag and the catalog digest. The legacy repository retains its separate `beta/` tag convention; neutral releases do not accept that legacy alias. Repository, asset, digest, canonical-version, and downgrade checks remain enforced.
- Keep the immutable migration plan as the authority for journal and handover verification while using the selected profile's current runtime environment, Stop generation, and reconnect state for observation. Other profiles retain their original observation inputs. This does not rewrite evidence or weaken plan equality, record version, operation ID, raw-byte SHA-256, ownership, Stop, delivery, binding, or handover checks. A stale or mismatched handover remains rejected.
- Retain completed migration information as history instead of replacing the current update status. Current checks, errors, release details, Download links, and available actions are no longer masked by an earlier completion message. Completion history hides retired migration controls without fabricating a successful check, installation, or provider connection.

Beta catalog entries remain **informational: Download, not Apply**. With beta updates enabled, a validated newer beta can expose its version, exact tag, and download URL, but this repair adds neither beta installation authority nor automatic installation. Changing beta consent does not install or restart the app.

This beta inherits beta.2's expanded-bubble sizing and session-list viewport improvements, matched-results cap clarification, localized representative/total session counts, and full-text tooltip/accessibility presentation. It also retains the simplified settings and explicit beta-update consent inherited from beta.1. Quit stops Desktop Pet only; Herdr and Tern keep running, and automatic-start preferences remain unchanged.

## Scope and compatibility

The neutral app, Core package, and paired update coordinator are product version `0.4.13-beta.3`. Shared contracts remain `0.1.0`; the legacy bridge remains `0.3.16`, with no new bridge release. Product identity remains `DesktopPet.app`, `io.github.hanbong5938.desktop-pet`, and `desktop-pet` / `desktop-pet-update-coordinator`. Protocol 4, observation capability 2, integration API 1, and migration handover protocol 1 are unchanged.

Bundled Herdr/Tern host integration revisions, provider selection, session routing, and connection protocols are unchanged. Stable `0.4.12` remains the only authorized migration target; beta installation does not qualify an old-source migration route. Existing installation-owner, updater-reservation, and Stop fences remain in force. No stable, main-channel, Homebrew tap, or wiki rollout is included.
