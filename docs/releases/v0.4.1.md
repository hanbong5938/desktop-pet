## Ownership and behavior

- Herdr owns the optional manager UI, four-locale text, authenticated selected-host inventory, protected plugin roots, confirmation and guarded durable host mutations. Its original host patch stays in the Herdr integration repository; installing an integration never patches or replaces a host.
- Core owns host-neutral preference access, bounded control transport, CAS and exact-operation uncertainty, offline ownership admission and shared lifecycle/profile persistence. Contracts retain a config-scoped preferences-owner FD, bound to the canonical config/state pair. A second state selection cannot write the same live config.
- Install/Remove change only optional-component availability. Open explicitly discovers the selected host. No uncertain mutation replay, alternate-host/CLI fallback or fabricated completion is permitted. Operation lifetime descriptors remain distinct from short admission descriptors.
- Native manager windows use readable dark appearance and the same floating level as Settings so the owning action can present them above Settings. Short manager admission explicitly unlocks on drop; it cannot be retained until exec by an unrelated fork. Long operation admission is intentionally not unlocked by that drop.
