01 / 观察◉

只显示已观测状态

气泡中的会话卡片显示空闲、运行中、等待输入或状态未知；不会推测代理的工作结果。

02 / 回复↗

向本地会话提交消息

从选定的本地代理卡片发送消息。Herdr 接收消息不代表工作完成；远程卡片仅供查看。

03 / 互动✳

Rubelia 会回应触碰

轻点头部或身体，或抚摸头部以触发反应。还可以拖动角色、调整大小。

Desktop Pet + Herdr

Apple Silicon Mac、macOS 13 或更新版本。源码构建需 Rust/Cargo、Bun、Node.js/npm、Xcode Command Line Tools，预构建无需这些工具。应用为 ad-hoc 签名，未经公证。Herdr 快照需兼容本地服务器（0.9.0+），回复另需 agent.prompt。可选 client-attach 自动启动需官方 Herdr 0.9.3 应用集成仓库的补丁和宿主构建指引，或实际支持钩子的宿主。原版 0.9.0/0.9.3 没有该钩子，插件安装不修改宿主。

brew install hanbong5938/tap/desktop-pet
desktop-pet --version
desktop-pet start
desktop-pet status
# Optional Herdr lifecycle integration:
herdr plugin install hanbong5938/herdr-desktop-pet

desktop-pet --herdr-socket /actual/path/to/herdr-api.sock start — registered Herdr-adapter backend only, never the private control socket.

Desktop Pet / Auto

新配置档默认为 Auto。Connection 显示已注册提供商的实际连接，而非安装检测。提供商 ID 是不透明值，操作权限来自 capability，而非名称前缀或路径。Auto 是同时观察而非回退选择。远程来源只读；Tern 允许回复，不允许删除工作树。接受提交不代表代理完成。

desktop-pet profile show --json
desktop-pet start
desktop-pet status

Core 拥有公共 lifecycle 持久化与 auto_start（默认 on），额外键由注册集成拥有。Herdr 所有者仅在 lifecycle.json 不存在时，在首次 lifecycle 写入的共享 profile writer 内原子初始化 exit_with_herdr:true。已有文件缺键时读 false，显式 false 保留。旧布尔 enabled（含 false）迁移为 auto_start。端点、启动元数据、其他所有者字段保留；保存到 lifecycle.json 而非 preferences.json。坏 JSON／值报错不重置，保存失败保留原策略。Auto／无适配器无需 Herdr 也保持运行；下文 Herdr 端点／断连规则仅适用于 Herdr 专用选择。

参阅使用指南、准确的配置档与发现契约及 A→B 迁移。把 status / Connection 中的实际可执行文件、config、state 三个值填入 Tern Configure，再 Connect。现有独立 Tern、beta、自定义配置档保留原地，绝不合并。

Desktop Pet + Tern

仅安装需要的集成。Herdr 是轻量消费者；Tern 不下载、构建、安装或自动启动原生应用。插件更新与卸载只影响集成，不删除共享应用、配置档或角色。常规应用更新不重新安装 Herdr 插件。

tern plugin install https://github.com/hanbong5938/tern-desktop-pet
desktop-pet profile show --json
desktop-pet start

Configure → Connect: actual executable / config_dir / state_dir. No automatic profile merge, native install or startup.

Core / prebuilt / source

预构建与源码安装在 core 检出目录中执行，而不是 Herdr 集成目录。默认仅预构建，下载或验证失败不会暗中回退源码编译。--source 明确仅构建当前 core，并使用该目录的 dist/DesktopPet.app。

git clone https://github.com/hanbong5938/desktop-pet.git
cd desktop-pet
# 已公开的不可变 v0.4.3 安装器及固定资产：
git checkout --detach v0.4.3
bash scripts/install.sh --prebuilt
# 若选择从同一个公开 v0.4.3 标签安装源码：
# bash scripts/install.sh --source

不可变 v0.4.3 的默认／--prebuilt 使用精确公开固定资产（历史 v0.4.0／v0.4.1 保留各自 pin）。下载／验证失败绝不暗中构建 source。显式 --source 构建所选 core 检出，包括实际公开 v0.4.3 标签。 standalone prebuilt 使用实际 OS 账户 home 的 Applications/DesktopPet.app，获准 source 使用 core 的 dist/DesktopPet.app。admission 可复用已验证健康现有所有者；请使用安装器报告的执行文件，勿假定 dist 路径。共享 locator 原子保存到账户 home .local/share/desktop-pet/installation.json，只是发现证据而非权限。无效显式路径／locator 不回退，执行文件／签名／capability／origin 每次重新验证。Brew 拥有实际 formula／prefix，不暗中接管 live／已预约的安装。

05 / 使用须知

常见问题

开始之前，了解以下几点。

能在 Intel Mac、Windows 或 Linux 上运行吗？

不能。原生发行版面向运行 macOS 13 及以上版本的 Apple 芯片 Mac。

消息发送成功是否代表代理已完成任务？

不是。选定本地会话的服务器支持 agent.prompt 时可以提交消息。成功仅表示 Herdr 已接收消息，并不表示代理已处理或完成任务。远程会话仅供查看。

原版 Herdr 会在客户端连接时自动启动应用吗？

不会。客户端连接时自动启动需要支持 client.attached 钩子的主机：可以将所提供的补丁应用到官方 Herdr 0.9.3 源码，或者使用明确支持该钩子的主机版本。原版 0.9.0 和 0.9.3 均不支持此钩子。

还内置其他角色吗？

没有，只内置 Rubelia。其他可选扩展包及其使用条款请参阅独立的官方角色仓库。
