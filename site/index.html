NATIVE DESKTOP COMPANION

에이전트 세션을 데스크톱에서 확인하고 로컬 에이전트에 답장하세요.

루벨리아의 말풍선에서 관측된 세션 상태를 보고 선택한 로컬 에이전트에 메시지를 제출할 수 있습니다. 접수 확인은 작업 완료가 아닙니다.

같은 네이티브 앱을 선택한 공용 또는 별도 프로필에서 Tern과 연결하거나 호스트 없이 캐릭터만 독립 실행할 수 있습니다.

03 / DESKTOP PET

설치와 선택형 연동

독립적인 네이티브 macOS 데스크톱 캐릭터입니다. 루벨리아는 터치에 반응하고 Herdr·Tern 등 등록된 제공자의 세션을 표시하며 해당 출처가 허용한 경우 답장을 보냅니다. 호스트 없이 캐릭터만 실행할 수도 있습니다.

게시 경계: 기존 Herdr v0.3.6은 protocol 3 / observation capability 1로 출시되었습니다. 독립 Desktop Pet v0.4.0(protocol 4 / capability 2 / integration API 1)·bridge v0.3.7·중립 포뮬러·연동 태그는 아직 공개되지 않았습니다. 실제 후보 패키지/VM 검사는 공개 설치 가능 여부와 별개이며 최종 수락 표는 미완료입니다. 아래 명령은 중립 cutover 안내이지 검증된 공개 설치가 아닙니다. 과거 문서·태그·자산은 변경 불가합니다.

중립 릴리스와 포뮬러가 실제로 게시된 뒤 공개 설치 명령은 다음과 같습니다:

Desktop Pet + Herdr

Apple Silicon Mac, macOS 13 이상. 소스 빌드는 Rust/Cargo·Bun·Node.js/npm·Xcode Command Line Tools가 필요하며 사전 빌드 설치에는 필요 없습니다. 앱은 ad-hoc 서명·미공증입니다. Herdr 스냅샷에는 호환 로컬 서버(0.9.0 이상), 답장에는 별도 agent.prompt가 필요합니다. 선택형 client-attach 자동 시작에는 공식 Herdr 0.9.3에 연동 저장소의 패치와 호스트 빌드 절차를 적용하거나 실제 훅 지원 호스트를 사용해야 합니다. 순정 0.9.0/0.9.3에는 훅이 없고 플러그인 설치는 호스트를 패치하지 않습니다.

brew install hanbong5938/tap/desktop-pet
desktop-pet --version
desktop-pet start
desktop-pet status
# Optional Herdr lifecycle integration:
herdr plugin install hanbong5938/herdr-desktop-pet

desktop-pet --herdr-socket /actual/path/to/herdr-api.sock start — registered Herdr-adapter backend only, never the private control socket.

Desktop Pet / Auto

새 프로필은 Auto입니다. Connection은 등록된 제공자의 실제 연결을 표시하며 설치 여부로 추측하지 않습니다. 제공자 ID는 불투명 값이고 작업 권한은 출처 이름 접두사·경로가 아니라 capability로 결정합니다. Auto는 동시 관찰이지 fallback이 아닙니다. 원격은 읽기 전용이며 Tern은 답장만 지원하고 worktree 제거는 지원하지 않습니다. 접수는 에이전트 완료가 아닙니다.

desktop-pet profile show --json
desktop-pet start
desktop-pet status

Core는 공통 lifecycle 저장과 auto_start(기본 on)를 소유하고 추가 키는 등록 연동이 소유합니다. Herdr 소유자는 lifecycle.json이 없을 때만 첫 lifecycle 쓰기의 공유 profile writer 안에서 exit_with_herdr:true를 원자적으로 초기화합니다. 기존 파일에서 키가 없으면 false이며 명시적 false도 유지합니다. 기존 boolean enabled는 false까지 auto_start로 이전합니다. endpoint·시작 메타데이터·다른 소유자의 필드를 보존하며 preferences.json이 아닌 lifecycle.json에 저장합니다. 잘못된 JSON/값은 초기화하지 않고 오류이며 저장 실패는 기존 실행 정책을 유지합니다. Auto/어댑터 없는 앱은 Herdr 없이 살아 있고 아래 Herdr endpoint·단절 규칙은 Herdr 전용 선택에서만 적용합니다.

사용법, 정확한 프로필·탐색 계약, A→B 이전 안내를 확인하세요. status 또는 Connection의 실제 실행 파일/config/state 세 값을 Tern Configure에 입력하고 Connect하세요. 기존 별도 Tern·beta·custom 프로필은 그 자리에서 보존하고 병합하지 않습니다.

Desktop Pet + Tern

필요한 연동만 설치하세요. Herdr는 얇은 consumer이며 Tern은 네이티브 앱을 다운로드·빌드·설치·자동 시작하지 않습니다. 플러그인 갱신·제거는 연동만 바꾸고 공용 앱·프로필·캐릭터는 남깁니다. 일반 앱 업데이트는 Herdr 플러그인을 재설치하지 않습니다.

tern plugin install https://github.com/hanbong5938/tern-desktop-pet
desktop-pet profile show --json
desktop-pet start

Configure → Connect: actual executable / config_dir / state_dir. No automatic profile merge, native install or startup.

Core / prebuilt / source

사전 빌드·소스 설치는 Herdr 연동이 아니라 core 체크아웃에서 실행합니다. 기본 설치는 prebuilt-only이며 다운로드·검증 실패를 소스 빌드로 숨기지 않습니다. --source는 현재 core 체크아웃만 빌드하고 그 dist/DesktopPet.app을 사용합니다.

git clone https://github.com/hanbong5938/desktop-pet.git
cd desktop-pet
# Requires neutral public assets; not yet published:
bash scripts/install.sh --prebuilt
# Explicit source alternative:
bash scripts/install.sh --source

기본/--prebuilt는 고정된 중립 공개 자산을 요구하며 아직 게시되지 않았습니다. 실패를 소스 빌드로 숨기지 않고 명시적 --source만 현재 검증된 core를 빌드합니다. standalone prebuilt는 실제 OS 계정 home의 Applications/DesktopPet.app, 승인된 source는 core의 dist/DesktopPet.app을 사용합니다. admission은 검증된 정상 기존 소유자를 재사용할 수 있으므로 추정 dist 경로가 아닌 설치기가 보고한 실행 파일을 사용하세요. 공유 locator는 계정 home .local/share/desktop-pet/installation.json에 원자 저장하며 탐색 근거일 뿐 권한이 아닙니다. 잘못된 명시 경로/locator는 fallback하지 않고 실행 파일·서명·capability·origin을 다시 검증합니다. Brew는 실제 formula/prefix를 소유하고 live/예약된 설치를 몰래 인수하지 않습니다.

Legacy A: 0.3.6 → bridge 0.3.7; explicit B: → neutral 0.4.0. Protocol-2 beta: retained helper → pinned 0.3.6 → A → B. Disposable account / VM required.

05 / GOOD TO KNOW

자주 묻는 질문

시작하기 전 알아둘 점을 모았습니다.

Intel Mac이나 Windows, Linux에서도 사용할 수 있나요?

아니요. 네이티브 배포 대상은 Apple Silicon Mac, macOS 13 이상입니다.

메시지 전송 성공은 에이전트 작업 완료를 뜻하나요?

아니요. 선택한 로컬 세션의 서버가 agent.prompt를 지원할 때 메시지를 제출할 수 있습니다. 성공은 Herdr가 접수했다는 뜻이며 에이전트가 처리하거나 완료했다는 뜻은 아닙니다. 원격 세션은 읽기 전용입니다.

순정 Herdr에서 클라이언트 연결 시 자동으로 시작되나요?

아니요. 자동 시작에는 client.attached 훅을 지원하는 호스트가 필요합니다. 공식 Herdr 0.9.3 소스에 제공된 패치를 적용하거나 해당 훅을 명시적으로 지원하는 호스트 릴리스를 사용하세요. 순정 0.9.0과 0.9.3은 지원하지 않습니다.

다른 캐릭터도 기본 제공되나요?

아니요. 루벨리아만 기본 제공됩니다. 별도 공식 캐릭터 저장소에서 선택형 팩과 사용 조건을 확인하세요.
